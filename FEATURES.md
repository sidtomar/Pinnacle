### Dynamic Research Agent - User-Defined Filters
- **Status:** In Progress
- **Branch:** `feature/dynamic-research-agent`
- **Started:** June 4, 2026
- **Description:** Allow users to dynamically search articles using filters (Therapy Area, Disease, Keywords, Publication Date) and trigger agentic pipeline to generate content cards
- **Key Features:**
  - [ ] Filter interface (Therapy Area, Disease, Keywords, Publication Date)
  - [ ] "Search PubMed" button to trigger pipeline
  - [ ] Simple loading indicator (iOS-style spinner)
  - [ ] Multiple articles generated per search
  - [ ] Auto-save to Content Library (Pending MA Review)
  - [ ] Download Database functionality
  - [ ] Results accumulate (don't overwrite)
  - [ ] Admin-only delete capability

**Technical Details:**
- Same agentic pipeline as Research Pipeline (Alpha→Beta→Gamma→Delta)
- User filters instead of pre-defined topics
- Hide agent status, show simple spinner
- Multiple search results stored, not replaced
